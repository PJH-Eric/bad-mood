# 請問，你在生氣什麼？

單機、純前端的對話模擬遊戲：她今天不知道為什麼在生氣，聽她說的話、選出最能讓她消氣的回答。**任何一題答錯（或超過時間沒回答）本關立刻 GAME OVER，重來。**

## 玩法
- 開始前輸入「她」（女友）的名字，對話中會代入。
- 共 20 個場景關卡（客廳、便利商店、早餐店、公車站、咖啡廳、電影院、百貨公司、夜市、餐廳、公園、遊樂園、海邊、圖書館、公司樓下、超市、車站月台、生日派對、溫泉旅館、演唱會、屋頂），依序解鎖。
- 每關 5～10 題：固定題依序出現，隨機題每次從題池抽出並插入；選項順序每次重洗。
- 答案有合理的、不合理的、也有無厘頭的，有些生氣的點看似微不足道。
- 作答時限隨關卡遞減：第 1 關 30 秒 → 第 20 關 8 秒。
- 快捷鍵：`1`～`4` 選答案、`Enter`／空白鍵 繼續、`Esc` 暫停。
- 進度與名字存在瀏覽器 localStorage，可在設定清除。

## 執行
不需安裝任何東西，直接用瀏覽器開啟 `index.html` 即可；也可用任何靜態伺服器，例如 `npx serve .`。

## 結構
| 檔案 | 說明 |
|---|---|
| `index.html` | 畫面骨架（標題、選關、對話、結算、設定） |
| `css/style.css` | 視覺小說風 UI（半透明藍玻璃對話框；所有元件自繪） |
| `js/art.js` | 手繪向量 SVG：人物表情、每個場景的女主角服裝、20 個場景底圖 |
| `js/art2.js` | 美術加強：透視地板、牆面質感、光暈景深、環境動畫、情緒特效 |
| `js/data-a.js` `js/data-b.js` | 題庫（第 1～10 關／第 11～20 關） |
| `js/audio.js` | WebAudio 即時合成的音效與 BGM |
| `js/game.js` | 遊戲流程 |
| `tests/verify.js` | 題庫與美術完整性檢查：`node tests/verify.js` |

## 新增／修改題目
在 `js/data-*.js` 的關卡 `fixed`（固定題）或 `pool`（隨機題池）加入：

```js
Q('angry', '她說的話，可用 {n} 代入名字', ['正解（可多個）'], ['錯誤選項 1', '錯誤選項 2', '…'], '答錯時她的反應', '答對時她的反應（可省略）')
```

情緒可用：`angry` `sulk` `sad` `shock` `cold` `happy` `blush` `normal`。改完執行 `node tests/verify.js` 檢查。

直向手機／平板會自動把畫面旋轉成橫向顯示。

除錯：網址加 `?debug=1` 可解鎖全部關卡。
